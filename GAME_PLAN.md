# Empire Rush — MVP

## Goal
Build a mobile-first, offline-first strategy game with a short, repeatable gameplay loop and optional monetization that never blocks core offline play.

## MVP gameplay
- Procedurally generated maps
- Settlement expansion
- Resource collection
- Buildings and upgrades
- Units and simple tactical combat
- Fog of war
- Random events
- Clear win/lose conditions
- Local save/progression
- 3–8 minute target sessions

## Monetization architecture
Core gameplay remains playable offline. Connectivity is optional for:
- Rewarded ads
- Interstitial ads used sparingly between completed sessions
- Cosmetic purchases
- Optional progression convenience purchases
- Analytics/crash reporting
- Cloud save and online features later

No paywall should prevent the player from playing offline.

## Commercial/IP rules
The Civ2025 source code is MIT licensed. Its original license/copyright notice must be retained. Third-party assets listed by Civ2025 are NOT assumed to share the code license; assets will be audited and replaced where commercial redistribution rights are unclear or unsuitable.

## Development principle
Ship a playable vertical slice first, then improve retention, presentation and monetization based on real playtesting rather than building a large feature set before testing the core loop.
